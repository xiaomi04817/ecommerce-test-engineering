# 电商系统 — 需求跟踪矩阵（三向追踪 RTM）

> 版本: v2.0 | 日期: 2026-06-23

---

## 追踪模型

```
需求 (REQ) ←→ 测试用例 (TC) ←→ 缺陷 (BUG)
     ↑                            ↑
     └───── 三向交叉追溯 ──────────┘
```

- **正向追踪**: 需求 → 用例 — 确保每个需求有测试覆盖
- **反向追踪**: 用例 → 需求 — 确保无冗余测试（每条用例都有需求来源）
- **缺陷→需求**: BUG → REQ — 识别缺陷集中的需求模块（质量热力图）
- **缺陷→用例**: BUG → TC — 评估测试用例的缺陷发现能力（漏测分析）

---

## 核心指标

| 指标 | 计算公式 | 目标值 |
|------|---------|--------|
| 需求覆盖率 | 有TC映射的REQ数 / 总REQ数 × 100% | 100% |
| 用例执行率 | 已执行TC数 / 总TC数 × 100% | 100% |
| 缺陷密度 | 某模块BUG数 / 该模块TC数 | 用于识别高风险模块 |
| 缺陷发现率 | 测试阶段发现BUG数 / 总BUG数 | ≥90% |
