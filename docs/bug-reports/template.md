# 严重等级定义

| 等级 | 定义 | 示例 |
|------|------|------|
| **Blocker** | 系统崩溃/数据丢失/核心流程完全不可用 | 无法登录、下单导致系统异常 |
| **Critical** | 核心功能严重缺陷，无替代方案 | 支付后状态未更新、库存超卖 |
| **Major** | 功能缺陷，有替代方案但不便 | 分页失效（可手动翻页）、搜索不准确 |
| **Minor** | 界面/提示信息问题，不影响功能 | 错误提示文案不清晰、字段对齐问题 |
| **Trivial** | 建议性改进，非缺陷 | 颜色搭配建议、文案优化 |

# 优先级定义

| 优先级 | 定义 |
|--------|------|
| **P0** | 立即修复，阻塞测试/发布 |
| **P1** | 本迭代内必须修复 |
| **P2** | 下个迭代修复 |
| **P3** | 视情况修复或记录为已知问题 |

# 缺陷生命周期

```
New ─→ Confirmed ─→ In Progress ─→ Fixed ─→ Verified ─→ Closed
  │                     ↑                        ↓
  └───── Reopened ←─────┘                        │
                    └─────────────────────────────┘
```
